# 🎬 Кинокладезь — Умный рекомендательный Telegram-бот

Персональный рекомендательный Telegram-бот фильмов и сериалов нового поколения на базе **локальных семантических эмбеддингов** (`rubert-tiny2`), динамического дообучения профиля вкусов (online centroid learning) и базы данных Кинопоиска.

---

## 🌟 Ключевые возможности

* 📱 **Telegram Mini App (Кино-Тиндер `kino.steins.ru`)**:
  * Полноценное веб-приложение прямо внутри Telegram с интерфейсом в стиле Tinder / Badoo.
  * Интерактивные свайпы карточек с физикой и анимацией (Framer Motion):
    * **Вправо** ➡️ Лайк (позитивное дообучение вкусов)
    * **Влево** ⬅️ Дизлайк (отталкивание вкусов)
    * **Вверх** ⬆️ В список «Буду смотреть»
  * Кнопка отмены последнего свайпа (Undo), виброотклик (Haptic Feedback) и модальное окно полного синопсиса.
  * 3 удобные вкладки: **Карточки**, **Мои списки** (вишлист/лайки) и **Фильтры** (по жанрам, рейтингу и годам).
* 🧠 **Интеллектуальные рекомендации**:
  * Каждому фильму соответствует семантический вектор синопсиса, атмосферы и жанров (312-мерное векторное пространство).
  * Вектор вкуса пользователя динамически сдвигается в сторону понравившихся тем при нажатии `❤️ Нравится` и отталкивается от нежелательных при `👎 Не моё`.
  * Время скоринга всей базы рекомендаций — **менее 20 миллисекунд** на CPU!
* ⚡ **Быстрый блиц-онбординг**:
  * При первом старте бот предлагает оценить 5–6 культовых разноплановых фильмов («Интерстеллар», «Зеленая миля», «1+1», «Бойцовский клуб» и др.), мгновенно формируя персональный вектор вкусов.
* 🃏 **Tinder-карточки фильмов в боте**:
  * Удобные инлайн-кнопки под постером каждого фильма с возможностью моментально перейти в WebApp.
* 🔍 **Умный гибридный поиск (On-Demand Cache)**:
  * Напишите название любого фильма в чат — бот найдет его в локальной базе или мгновенно выгрузит через Kinopoisk API, автоматически векторизует и добавит в базу.
  * Поддерживается Inline-режим (`@bot Название`) в любых чатах Telegram.
* 🎭 **Фильтры под настроение**:
  * Возможность сузить поток рекомендаций по жанру (фантастика, драма, комедия, триллер и др.) или типу (фильмы / сериалы).
* 🗂️ **Персональные списки**:
  * Просмотр и управление списками «Буду смотреть» и «Понравившиеся» с интерактивной пагинацией и удалением.

```
│   │   └── telegram.ts            # Telegram WebApp SDK и Haptics
│   ├── vite.config.ts             # Раздача статики и проксирование /api на бэкенд

│   ├── auth.py                    # Валидация Telegram initData (HMAC-SHA256)

```

## 🚀 Установка и запуск

### 1. Клонирование и виртуальное окружение
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```env
BOT_TOKEN=ВАШ_ТЕЛЕГРАМ_ТОКЕН_ОТ_BOTFATHER
KINOPOISK_API_KEY=71c5dd47-2ab2-40d4-bb00-4974097af5b6
DATABASE_PATH=bot_database.db

# Ограничение нагрузки на CPU (актуально для слабых VPS):
DOCKER_CPUS=0.8
CPU_THREADS=1
TELEGRAM_CONCURRENT_UPDATES=4
```

### 3. Сидирование базы данных (опционально)
База данных уже предзаполнена ~1000 культовыми фильмами с эмбеддингами. При необходимости догрузить фильмы из API:
```bash
python3 scripts/seed_db.py --max-films 1500
```

### 4. Запуск бота

**Локально:**
```bash
python3 main.py
```

**Через Docker Compose (рекомендуется для VPS):**
```bash
docker compose up -d
```
> В `docker-compose.yml` уже настроены лимиты CPU (`cpus: 0.8`), приоритеты планировщика (`cpu_shares: 512`) и ограничение потоков PyTorch (`CPU_THREADS: 1`), чтобы бот не перегружал сервер и не выбивал SSH-соединение.
